# Puerta · control de acceso

Escáner de boletos con QR para la entrada de eventos. Lee el QR con la cámara del celular y consulta/registra la entrada en el Google Sheet del evento (vía Apps Script).

- Abrir: https://robpedrozariveira07.github.io/puerta-eventos/
- Link directo a un evento: `?evento=<id>`
- Para agregar o desactivar eventos, edita la lista `EVENTOS` en `index.html` (campo `activo`).
